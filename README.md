# تشجير العراق — موقع الحملة

موقع ويب عربي (RTL) كامل لحملة وطنية لدعم التشجير في العراق، مبني بـ HTML و CSS و JavaScript فقط بدون أي اعتماديات.

## الصفحات

| الملف | المحتوى |
| --- | --- |
| `index.html` | الواجهة الرئيسية: البوسترات، البرامج التوعوية، الإحصائيات، الشريط المتحرك، وقائمة النقاط الثلاث |
| `about.html` | من نحن: قصة الحملة، أهميتها، والمؤسسون مع روابط إنستغرام |
| `donate.html` | صفحة التبرع: اختيار المبلغ، طرق الدفع، شريط تقدم الهدف، وإيصال التبرع |

## التشغيل

افتح `index.html` مباشرة في المتصفح، أو شغّل خادماً محلياً:

```bash
python -m http.server 8000
```

ثم افتح: `http://localhost:8000`

## تعديل روابط إنستغرام (مهم)

روابط المؤسسين الحالية تجريبية. استبدلها بالحسابات الرسمية من داخل `about.html`:

```html
<a href="https://www.instagram.com/USERNAME/" target="_blank" rel="noopener noreferrer">الاسم</a>
```

ابحث في الملف عن التعليق `✏️ استبدل روابط الإنستغرام` وعدّل الروابط الأربعة (في اسم المؤسس وزر «إنستغرام» معاً).

## الميزات التفاعلية

- **قائمة النقاط الثلاث** على يمين الشاشة: إنشاء حساب، التبرع، من نحن.
- **ساب تايتل متحرك**: عبارات متغيرة بتأثير الكتابة داخل الواجهة الرئيسية، وشريط نصوص متحرك أسفلها.
- **بوسترات SVG** مرسومة يدوياً، وتُعرض بحجم أكبر عند الضغط عليها.
- **نموذج حساب** يُحفظ في `localStorage` (عرض تجريبي بدون خادم).
- **نموذج تبرع** يحسب عدد الشتلات، يحدّث نسبة الهدف، ويصدر رقم إيصال تجريبي.
- دعم كامل للجوال، وتقليل الحركة لمن يفضّل ذلك، وإتاحة (Accessibility) بتقييم 100/100.

## التخصيص السريع

كل الألوان والخطوط والمسافات معرّفة في بداية `assets/css/style.css` داخل `:root`:

```css
--bg: #05100c;
--green: #2dd47a;
--mint: #6ee7b7;
--gold: #e6c07b;
```

## ملاحظة

نماذج الحساب والتبرع أمامية فقط (Front-end demo). لربطها بخادم حقيقي، استبدل معالجات `submit` في `assets/js/main.js` بطلبات API.
